# Digital Swirl TS
### Rewrite of [Digital Swirl](https://github.com/SonicOnset/DigitalSwirl-Client) in [roblox-ts](https://roblox-ts.com)
Some creative liberties have been taken during the rewrite, this is not a 1:1 translation. Attempts were made to convert as much of the project as possible for a Rojo workflow, to make this project as easy as possible to set up. Much of the original code was edited and reformatted in an attempt to make the framework more modular.

## Building
Source will not run out of the box, some setup is required; this repo does not contain any assets, you will have to examine the code to reconstruct the asset layouts.

Run `npm install` to install all dependencies in `package.json`, follow the [Rojo build & serve tutorial](https://rojo.space/docs/v7/getting-started/new-game/#building-your-place) to begin editing.
